{# Custom homepage template — assigned via `template: home.html` in docs/en/index.md front matter. Every other page keeps the default `main.html` untouched. Extends main.html (which is itself an unmodified `{% extends "base.html" %}` per Zensical's own convention — see the customization guide: "override main.html instead of base.html"), then: - `styles`: adds the self-hosted landing fonts + home.css, on top of the normal theme stylesheet (kept via `{{ super() }}`). Every visible string is read from the page's own front matter with the English text as the fallback, so the German build reuses this template rather than forking it. Zensical has no native i18n and the site is two separate builds; a second copy of this file would drift the moment either one is touched. See docs/de/index.md for the German values. Asset paths are absolute and carry the /en/ prefix on purpose: only the English build vendors home.css, home.js and the fonts, and the German site reaches the same files on the same origin instead of carrying a second copy. Same trade-off, and the same hard dependency, as panel-tools.js — see the note in zensical.de.toml. - `hero`: fills the (empty-by-default) hero block with the hardware-chain diagram, headline, and CTAs — this is the same block zensical.org's own homepage uses for its hero. - `scripts`: adds home.js (progressive enhancement only; the page is fully functional and legible with it absent). The theme toggle, search, header, footer, and the rest of the site chrome are all inherited unchanged. Sidebars are hidden via `hide: [navigation, toc]` in index.md's front matter (the theme's own documented mechanism, not a template override). #} {% extends "main.html" %} {% block styles %} {{ super() }} {% endblock %} {% block hero %}
