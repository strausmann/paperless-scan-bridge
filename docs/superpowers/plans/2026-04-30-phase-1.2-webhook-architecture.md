# Phase 1.2 Implementation Plan — Webhook-Driven Scan Architecture

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the first end-to-end webhook-driven scan path for
`paperless-scan-bridge` Phase 1.2: a remote caller POSTs to a
per-profile webhook URL, the bridge drives a SANE scanner via a
sibling `sane-runtime` container, assembles the result into a
single multi-page PDF (real OCR / splitting deferred to Phase 1.3),
and uploads it to Paperless-ngx via REST API. Profiles are persisted
in SQLite and exposed through a CRUD HTTP API ready for the future
web UI.

**Architecture:** Two containers. `scan-bridge` is a distroless Go
binary owning the HTTP API, the profile DB, the job queue, the
output dispatcher, and a hand-rolled SANE-net client. `sane-runtime`
is a Debian-slim container that hosts `saned` (TCP/6566) plus the
SANE drivers (`avision`-only via `dll.conf` pruning). The two
containers communicate exclusively over the SANE-net protocol —
`scan-bridge` never shells out, never holds USB devices, stays
distroless.

**Tech Stack:**

- Go 1.22+ (single static binary, ARM64 cross-compile via
  `GOOS=linux GOARCH=arm64 CGO_ENABLED=0`)
- `modernc.org/sqlite` — pure-Go SQLite driver (no CGO, distroless-
  compatible). Uses CGo-style API but transpiled to Go
- `github.com/golang-migrate/migrate/v4` — schema migrations
- `github.com/go-chi/chi/v5` — minimal HTTP router
- `gopkg.in/yaml.v3` — YAML profile import/export
- `github.com/getsops/sops/v3` — SOPS decryption (Go API, no CLI
  shell-out)
- `github.com/prometheus/client_golang` — metrics
- Hand-rolled SANE-net client in `internal/sanenet/` (resolves
  spec open question O-5 — choice rationale below)
- Docker buildx bake for multi-arch container builds
- Tilt for local dev loop (developer convenience, not required
  for CI)
- Bats for shell-script tests (the bootstrap script in
  `deploy/bootstrap/`, when it lands in a later phase)
- `github.com/stretchr/testify` for assertions in Go tests

**Spec resolution (decisions taken in this plan, not the spec):**

- **O-1 (Paperless ASN reservation):** Phase 1.2 derives next-ASN
  from `GET /api/documents/?ordering=-archive_serial_number&page_size=1`,
  guarded by the in-process job-queue mutex (only one scan runs at
  a time, so no race). Documented as a Paperless-side open issue
  for a future "reserve ASN" endpoint.
- **O-2 (OTel tracing):** **Defer.** Phase 1.2 emits Prometheus
  metrics + structured logs with `scanId` correlation. OTel can
  be added later without API changes.
- **O-3 (Token storage):** **Plain in SQLite.** Documented threat
  model: SQLite file is itself a deployment-secret-grade artifact.
  Adding hashing is a Phase 2.x security review item.
- **O-4 (saned via Unix socket vs TCP):** **TCP.** Simpler Go-side
  code; container network isolation is the security boundary.
- **O-5 (Go SANE-net library):** **Hand-rolled** in
  `internal/sanenet/`. The protocol is documented and stable; we
  control the dependency, no third-party-update risk, ARM64 trivial.

// Package config loads scan-bridge runtime configuration from
// environment variables and resolves secret references against
// Docker secrets, env vars, or SOPS-encrypted files.
package config

import (
	"fmt"
	"os"
)

// Config is the loaded runtime configuration.
type Config struct {
	DBPath      string
	HTTPAddr    string
	SANENetAddr string
	LogLevel    string

	// SecretsFile, if set, is a path to a SOPS-encrypted YAML file.
	SecretsFile string
	// AgeKeyFile, if SecretsFile is set, holds the age key for
	// decryption.
	AgeKeyFile string
}

const (
	defaultDBPath      = "/data/profiles.db"
	defaultHTTPAddr    = ":8080"
	defaultSANENetAddr = "sane-runtime:6566"
	defaultLogLevel    = "info"
)

var validLogLevels = map[string]struct{}{
	"debug": {}, "info": {}, "warn": {}, "error": {},
}

// LoadFromEnv reads configuration from environment variables,
// applying defaults for any unset value.
func LoadFromEnv() (Config, error) {
	cfg := Config{
		DBPath:      envOr("SCAN_BRIDGE_DB_PATH", defaultDBPath),
		HTTPAddr:    envOr("SCAN_BRIDGE_HTTP_ADDR", defaultHTTPAddr),
		SANENetAddr: envOr("SCAN_BRIDGE_SANE_NET_ADDR", defaultSANENetAddr),
		LogLevel:    envOr("SCAN_BRIDGE_LOG_LEVEL", defaultLogLevel),
		SecretsFile: os.Getenv("SCAN_BRIDGE_SECRETS_FILE"),
		AgeKeyFile:  os.Getenv("SCAN_BRIDGE_AGE_KEY_FILE"),
	}
	if _, ok := validLogLevels[cfg.LogLevel]; !ok {
		return Config{}, fmt.Errorf("config: invalid log level %q (allowed: debug, info, warn, error)", cfg.LogLevel)
	}
	return cfg, nil
}

func envOr(key, fallback string) string {
	if v, ok := os.LookupEnv(key); ok && v != "" {
		return v
	}
	return fallback
}
```

package config

import (
	"fmt"
	"os"
	"path/filepath"
	"strings"
)

// Resolver looks up named secrets in priority order: Docker
// secrets directory, environment variable, then SOPS-encrypted
// file (Phase 1.2 ships Docker + env paths; SOPS path is wired
// through but documented as advanced configuration).
type Resolver struct {
	// SecretsDir is the directory holding Docker-style secrets,
	// typically /run/secrets. Empty disables this lookup.
	SecretsDir string
}

// Resolve returns the secret value for name. The same name maps to:
//   - file <SecretsDir>/<name>
//   - env  <NAME-uppercase>
//
// First non-empty hit wins. Trailing whitespace (newlines, spaces)
// is trimmed.
func (r Resolver) Resolve(name string) (string, error) {
	if r.SecretsDir != "" {
		path := filepath.Join(r.SecretsDir, name)
		if data, err := os.ReadFile(path); err == nil {
			v := strings.TrimRight(string(data), " \t\r\n")
			if v != "" {
				return v, nil
			}
		}
	}
	envKey := strings.ToUpper(name)
	if v, ok := os.LookupEnv(envKey); ok && v != "" {
		return strings.TrimRight(v, " \t\r\n"), nil
	}
	return "", fmt.Errorf("config: no secret found for %q (searched %s/%s and env %s)",
		name, r.SecretsDir, name, envKey)
}
```

package db

import (
	"database/sql"
	"embed"
	"errors"
	"fmt"
	"os"
	"path/filepath"

	"github.com/golang-migrate/migrate/v4"
	migsqlite "github.com/golang-migrate/migrate/v4/database/sqlite"
	"github.com/golang-migrate/migrate/v4/source/iofs"
	_ "modernc.org/sqlite"
)

//go:embed migrations/*.sql
var migrationFS embed.FS

// Open opens (and creates if missing) the SQLite database at path,
// applies all pending migrations, and returns the underlying
// *sql.DB. Directories are created as needed.
func Open(path string) (*sql.DB, error) {
	if dir := filepath.Dir(path); dir != "" && dir != "." {
		if err := os.MkdirAll(dir, 0o755); err != nil {
			return nil, fmt.Errorf("db: mkdir %q: %w", dir, err)
		}
	}

	conn, err := sql.Open("sqlite", path+"?_pragma=foreign_keys(1)&_pragma=journal_mode(WAL)")
	if err != nil {
		return nil, fmt.Errorf("db: open: %w", err)
	}
	if err := conn.Ping(); err != nil {
		_ = conn.Close()
		return nil, fmt.Errorf("db: ping: %w", err)
	}

	if err := applyMigrations(conn); err != nil {
		_ = conn.Close()
		return nil, err
	}
	return conn, nil
}

func applyMigrations(conn *sql.DB) error {
	src, err := iofs.New(migrationFS, "migrations")
	if err != nil {
		return fmt.Errorf("db: build migration source: %w", err)
	}
	drv, err := migsqlite.WithInstance(conn, &migsqlite.Config{})
	if err != nil {
		return fmt.Errorf("db: migrate driver: %w", err)
	}
	m, err := migrate.NewWithInstance("iofs", src, "sqlite", drv)
	if err != nil {
		return fmt.Errorf("db: migrate instance: %w", err)
	}
	if err := m.Up(); err != nil && !errors.Is(err, migrate.ErrNoChange) {
		return fmt.Errorf("db: migrate up: %w", err)
	}
	return nil
}

// Validate returns an error if the profile is malformed in any way
// that should reject it before persistence. Errors aim to name the
// offending field for caller diagnostics.
func (p Profile) Validate() error {
	if strings.TrimSpace(p.Name) == "" {
		return errors.New("profile: name is required")
	}
	if len(p.Token) < 40 {
		return fmt.Errorf("profile: token must be at least 40 chars (got %d)", len(p.Token))
	}
	if p.Scan.Resolution < 75 || p.Scan.Resolution > 600 {
		return fmt.Errorf("profile: scan.resolution out of range 75..600 (got %d)", p.Scan.Resolution)
	}
	switch p.Scan.Mode {
	case "Lineart", "Gray", "Color":
	default:
		return fmt.Errorf("profile: scan.mode invalid %q", p.Scan.Mode)
	}
	switch p.Splitting.ASNMode {
	case ASNRequired, ASNDisabled:
	default:
		return fmt.Errorf("profile: splitting.asn_mode invalid %q", p.Splitting.ASNMode)
	}
	if p.Splitting.ASNMode == ASNRequired {
		switch p.Splitting.ASNPageHandling {
		case ASNPageDiscard, ASNPageKeep:
		default:
			return fmt.Errorf("profile: splitting.asn_page_handling invalid %q", p.Splitting.ASNPageHandling)
		}
		switch p.Splitting.OnMissingFirstASN {
		case OnMissingASNAutoCreate, OnMissingASNError:
		default:
			return fmt.Errorf("profile: splitting.on_missing_first_asn invalid %q", p.Splitting.OnMissingFirstASN)
		}
	}
	switch p.Paperless.DefaultTagStrategy {
	case TagAdd, TagOverride, TagRemove:
	default:
		return fmt.Errorf("profile: paperless.default_tag_strategy invalid %q", p.Paperless.DefaultTagStrategy)
	}
	if len(p.Outputs) == 0 {
		return errors.New("profile: outputs must contain at least one entry")
	}
	for i, o := range p.Outputs {
		if o.Target != OutputPaperlessAPI {
			return fmt.Errorf("profile: outputs[%d].target unsupported %q (Phase 1.2 supports only paperless-api)", i, o.Target)
		}
		if o.APIURL == "" {
			return fmt.Errorf("profile: outputs[%d].api_url required", i)
		}
		if o.APITokenSecret == "" {
			return fmt.Errorf("profile: outputs[%d].api_token_secret required", i)
		}
	}
	switch p.Response.DefaultMode {
	case ResponseSync, ResponseAsync:
	default:
		return fmt.Errorf("profile: response.default_mode invalid %q", p.Response.DefaultMode)
	}
	return nil
}

// NewToken returns a fresh URL-safe random token of 32 bytes
// (encoded ~43 chars), suitable as the profile webhook secret.
func NewToken() (string, error) {
	var b [32]byte
	if _, err := rand.Read(b[:]); err != nil {
		return "", fmt.Errorf("profile: rand: %w", err)
	}
	return base64.RawURLEncoding.EncodeToString(b[:]), nil
}

package profile

import (
	"context"
	"crypto/rand"
	"database/sql"
	"encoding/json"
	"errors"

	"time"

// ErrNotFound is returned when no profile matches the lookup key.
var ErrNotFound = errors.New("profile: not found")

// Store persists Profiles to a SQLite database.
type Store struct {
	db *sql.DB
}

// NewStore returns a Store wrapping conn. The DB schema must
// already be migrated (see internal/db.Open).
func NewStore(conn *sql.DB) *Store {
	return &Store{db: conn}
}

// Create inserts p, generating ID and timestamps if missing.
// Returns the persisted profile (with all server-generated fields).
func (s *Store) Create(ctx context.Context, p Profile) (Profile, error) {
	if err := p.Validate(); err != nil {
		return Profile{}, err
	}
	if p.ID == "" {
		id, err := newULID()
		if err != nil {
			return Profile{}, err
		}
		p.ID = id
	}
	now := time.Now().UTC().Format(time.RFC3339Nano)
	p.CreatedAt = now
	p.ModifiedAt = now

	cols, vals, err := profileColumns(p)
	if err != nil {
		return Profile{}, err
	}
	if _, err := s.db.ExecContext(ctx, profileInsertSQL, vals...); err != nil {
		return Profile{}, fmt.Errorf("profile.Create: %w", err)
	}
	_ = cols
	return p, nil
}

// Update overwrites the row identified by p.ID, refreshing
// ModifiedAt. Token rotation is handled separately via RotateToken.
func (s *Store) Update(ctx context.Context, p Profile) (Profile, error) {
	if err := p.Validate(); err != nil {
		return Profile{}, err
	}
	p.ModifiedAt = time.Now().UTC().Format(time.RFC3339Nano)

	res, err := s.db.ExecContext(ctx, profileUpdateSQL,
		p.Name, p.Token, boolToInt(p.Enabled),
		mustJSON(p.Scan), mustJSON(p.Splitting), mustJSON(p.Paperless),
		mustJSON(p.Naming), mustJSON(p.Outputs), mustJSON(p.Response),
		mustJSON(p.Metadata), p.ScanCountTotal, p.ModifiedAt, p.ID,
	)
	if err != nil {
		return Profile{}, fmt.Errorf("profile.Update: %w", err)
	}
	if rows, _ := res.RowsAffected(); rows == 0 {
		return Profile{}, ErrNotFound
	}
	return p, nil
}

// Delete removes a profile by ID. Returns ErrNotFound if the row
// did not exist.
func (s *Store) Delete(ctx context.Context, id string) error {
	res, err := s.db.ExecContext(ctx, "DELETE FROM profiles WHERE id = ?", id)
	if err != nil {
		return fmt.Errorf("profile.Delete: %w", err)
	}
	if rows, _ := res.RowsAffected(); rows == 0 {
		return ErrNotFound
	}
	return nil
}

// Get fetches by ID.
func (s *Store) Get(ctx context.Context, id string) (Profile, error) {
	row := s.db.QueryRowContext(ctx, profileSelectByIDSQL, id)
	return scanProfileRow(row)
}

// GetByToken fetches by webhook token.
func (s *Store) GetByToken(ctx context.Context, token string) (Profile, error) {
	row := s.db.QueryRowContext(ctx, profileSelectByTokenSQL, token)
	return scanProfileRow(row)
}

// List returns all profiles ordered by name.
func (s *Store) List(ctx context.Context) ([]Profile, error) {
	rows, err := s.db.QueryContext(ctx, profileSelectAllSQL)
	if err != nil {
		return nil, fmt.Errorf("profile.List: %w", err)
	}
	defer rows.Close()

	var out []Profile
	for rows.Next() {
		p, err := scanProfileRowMulti(rows)
		if err != nil {
			return nil, err
		}
		out = append(out, p)
	}
	return out, rows.Err()
}

// RotateToken assigns a new random token to the named profile and
// returns the updated profile.
func (s *Store) RotateToken(ctx context.Context, id string) (Profile, error) {
	tok, err := NewToken()
	if err != nil {
		return Profile{}, err
	}
	now := time.Now().UTC().Format(time.RFC3339Nano)
	res, err := s.db.ExecContext(ctx,
		"UPDATE profiles SET token = ?, modified_at = ? WHERE id = ?",
		tok, now, id,
	)
	if err != nil {
		return Profile{}, fmt.Errorf("profile.RotateToken: %w", err)
	}
	if rows, _ := res.RowsAffected(); rows == 0 {
		return Profile{}, ErrNotFound
	}
	return s.Get(ctx, id)
}

const profileInsertSQL = `
INSERT INTO profiles (
    id, name, token, enabled,
    scan_json, splitting_json, paperless_json, naming_json, outputs_json,
    response_json, metadata_json, scan_count_total,
    created_at, modified_at
) VALUES (?,?,?,?,?,?,?,?,?,?,?,?,?,?)`

const profileUpdateSQL = `
UPDATE profiles SET
    name = ?, token = ?, enabled = ?,
    scan_json = ?, splitting_json = ?, paperless_json = ?,
    naming_json = ?, outputs_json = ?, response_json = ?,
    metadata_json = ?, scan_count_total = ?, modified_at = ?
WHERE id = ?`

func scanProfileRow(r rowScanner) (Profile, error) {
	var p Profile
	var enabledInt int
	var scanJSON, splittingJSON, paperlessJSON, namingJSON,
		outputsJSON, responseJSON, metadataJSON string

	err := r.Scan(
		&p.ID, &p.Name, &p.Token, &enabledInt,
		&scanJSON, &splittingJSON, &paperlessJSON, &namingJSON, &outputsJSON,
		&responseJSON, &metadataJSON, &p.ScanCountTotal, &p.CreatedAt, &p.ModifiedAt,
	)
	if err != nil {
		if errors.Is(err, sql.ErrNoRows) {
			return Profile{}, ErrNotFound
		}
		return Profile{}, fmt.Errorf("profile: scan row: %w", err)
	}
	p.Enabled = enabledInt == 1
	if err := jsonInto(scanJSON, &p.Scan); err != nil {
		return Profile{}, err
	}
	if err := jsonInto(splittingJSON, &p.Splitting); err != nil {
		return Profile{}, err
	}
	if err := jsonInto(paperlessJSON, &p.Paperless); err != nil {
		return Profile{}, err
	}
	if err := jsonInto(namingJSON, &p.Naming); err != nil {
		return Profile{}, err
	}
	if err := jsonInto(outputsJSON, &p.Outputs); err != nil {
		return Profile{}, err
	}
	if err := jsonInto(responseJSON, &p.Response); err != nil {
		return Profile{}, err
	}
	if err := jsonInto(metadataJSON, &p.Metadata); err != nil {
		return Profile{}, err
	}
	return p, nil
}

func mustJSON(v any) string {
	b, err := json.Marshal(v)

		// validators run before persistence, so all of our types are
		// guaranteed-marshalable. A panic here is a developer bug.
		panic(fmt.Sprintf("profile: marshal: %v", err))

func jsonInto(s string, v any) error {
	if s == "" {
		return nil
	}
	if err := json.Unmarshal([]byte(s), v); err != nil {
		return fmt.Errorf("profile: unmarshal column: %w", err)
	}
	return nil
}

// newULID returns a 26-char Crockford-base32 ULID-style identifier.
// We use a small pure-Go implementation rather than pulling a ULID
// dependency just for this; collisions are practically impossible.
func newULID() (string, error) {
	var b [16]byte
	if _, err := rand.Read(b[:]); err != nil {
		return "", err
	}
	const alphabet = "0123456789ABCDEFGHJKMNPQRSTVWXYZ"
	var out [26]byte
	for i := range out {
		out[i] = alphabet[int(b[i%16])%32]
	}
	return string(out[:]), nil
}

package profile

import (
	"bytes"
	"errors"
	"fmt"
	"io"
	"strings"

	"gopkg.in/yaml.v3"
)

// EncodeYAML writes p as YAML to w.
func EncodeYAML(w io.Writer, p Profile) error {
	enc := yaml.NewEncoder(w)
	enc.SetIndent(2)
	if err := enc.Encode(p); err != nil {
		return fmt.Errorf("profile: yaml encode: %w", err)
	}
	return enc.Close()
}

// DecodeYAML reads YAML from r and returns the decoded Profile.
// It rejects YAML that appears to embed a plaintext secret in the
// outputs[].api_token field — the schema only accepts
// api_token_secret (a name pointing at the resolver chain).
func DecodeYAML(r io.Reader) (Profile, error) {
	var buf bytes.Buffer
	if _, err := io.Copy(&buf, r); err != nil {
		return Profile{}, fmt.Errorf("profile: yaml read: %w", err)
	}
	body := buf.Bytes()

	if containsPlaintextSecret(body) {
		return Profile{}, errors.New("profile: yaml contains plaintext secret in outputs.api_token; use api_token_secret instead")
	}

	var p Profile
	if err := yaml.Unmarshal(body, &p); err != nil {
		return Profile{}, fmt.Errorf("profile: yaml decode: %w", err)
	}
	return p, nil
}

func containsPlaintextSecret(body []byte) bool {
	// Cheap textual heuristic — the parser would silently ignore
	// unknown fields, so we look for the disallowed key by hand.
	return bytes.Contains(body, []byte("api_token:")) &&
		!strings.Contains(string(body), "api_token_secret:")
}

		return

		Addr:              cfg.HTTPAddr,
		Handler:           router,
		ReadHeaderTimeout: 10 * time.Second,

	ctx, cancel := signal.NotifyContext(context.Background(),
		syscall.SIGINT, syscall.SIGTERM)
	defer cancel()

		fmt.Fprintf(stdout, "scan-bridge %s listening on %s\n", Version, cfg.HTTPAddr)
		if err := srv.ListenAndServe(); err != nil && !errors.Is(err, http.ErrServerClosed) {
			fmt.Fprintf(stdout, "scan-bridge: http error: %v\n", err)
		}
	}()

	<-ctx.Done()
	shutdown, cancelShutdown := context.WithTimeout(context.Background(), 10*time.Second)
	defer cancelShutdown()
	_ = srv.Shutdown(shutdown)
	return 0
}

// Package tag implements the per-call tag-merge strategy described
// in the Phase 1.2 spec. Three strategies (add, override, remove)
// can be set as a profile default; each webhook call may override
// the strategy for that single call.
package tag

import (
	"github.com/strausmann/paperless-scan-bridge/components/scan-bridge/internal/profile"
)

// Merge resolves the final tag list for a scan.
//
//   - defaults: the profile-level default tags
//   - profileStrategy: the profile-level default strategy
//   - callerTags: the tags provided by the webhook caller
//   - callerStrategy: optional override, "" means "use profileStrategy"
//
// If callerTags is empty, defaults are returned unchanged (the
// strategy has no input to act on).
func Merge(
	defaults []string,
	profileStrategy profile.TagStrategy,
	callerTags []string,
	callerStrategy profile.TagStrategy,
) []string {
	if len(callerTags) == 0 {
		out := make([]string, len(defaults))
		copy(out, defaults)
		return out
	}
	strategy := callerStrategy
	if strategy == "" {
		strategy = profileStrategy
	}

	switch strategy {
	case profile.TagOverride:
		out := make([]string, len(callerTags))
		copy(out, callerTags)
		return dedupe(out)
	case profile.TagRemove:
		return without(defaults, callerTags)
	case profile.TagAdd:
		return dedupe(append(append([]string{}, defaults...), callerTags...))
	default:
		// Unknown strategy: behave like add for safety.
		return dedupe(append(append([]string{}, defaults...), callerTags...))
	}
}

func dedupe(in []string) []string {
	seen := make(map[string]struct{}, len(in))
	out := make([]string, 0, len(in))
	for _, s := range in {
		if _, ok := seen[s]; ok {
			continue
		}
		seen[s] = struct{}{}
		out = append(out, s)
	}
	return out
}

func without(base, remove []string) []string {
	rm := make(map[string]struct{}, len(remove))
	for _, s := range remove {
		rm[s] = struct{}{}
	}
	out := make([]string, 0, len(base))
	for _, s := range base {
		if _, ok := rm[s]; ok {
			continue
		}
		out = append(out, s)
	}
	return out
}

```go
// Package sanenet implements the subset of the SANE-net wire
// protocol that scan-bridge needs to drive a saned-hosted scanner:
// init, list devices, open, get/set option, get parameters, start,
// read image bytes, close. The protocol is binary, big-endian, and
// well-documented in the upstream SANE source under
// frontend/saned.c and backend/sanei_net.h.
package sanenet

import (
	"encoding/binary"
	"fmt"
	"io"
)

// rpcCode constants (from SANE_NET_* in saned.c).
const (
	rpcInit                   int32 = 0
	rpcGetDevices             int32 = 1
	rpcOpen                   int32 = 2
	rpcClose                  int32 = 3
	rpcGetOptionDescriptors   int32 = 4
	rpcControlOption          int32 = 5
	rpcGetParameters          int32 = 6
	rpcStart                  int32 = 7
	rpcCancel                 int32 = 8
	rpcAuthorize              int32 = 9
	rpcExit                   int32 = 10
)

// SANE_STATUS_* values used by Phase 1.2.
type Status int32

const (
	StatusGood        Status = 0
	StatusUnsupported Status = 1
	StatusCancelled   Status = 2
	StatusDeviceBusy  Status = 3
	StatusInvalid     Status = 4
	StatusEOF         Status = 5
	StatusJammed      Status = 6
	StatusNoDocs      Status = 7 // historical: 7 in older saned, 8 in newer
	StatusCoverOpen   Status = 8
	StatusIOError     Status = 9
	StatusNoMem       Status = 10
	StatusAccessDenied Status = 11
)

// String returns a stable textual description for the status,
// suitable for log lines and error messages.
func (s Status) String() string {
	switch s {
	case StatusGood:
		return "GOOD"
	case StatusUnsupported:
		return "UNSUPPORTED"
	case StatusCancelled:
		return "CANCELLED"
	case StatusDeviceBusy:
		return "DEVICE_BUSY"
	case StatusInvalid:
		return "INVALID"
	case StatusEOF:
		return "EOF"
	case StatusJammed:
		return "JAMMED"
	case StatusNoDocs:
		return "NO_DOCS"
	case StatusCoverOpen:
		return "COVER_OPEN"
	case StatusIOError:
		return "IO_ERROR"
	case StatusNoMem:
		return "NO_MEM"
	case StatusAccessDenied:
		return "ACCESS_DENIED"
	default:
		return fmt.Sprintf("UNKNOWN(%d)", int32(s))
	}
}

func writeWord(w io.Writer, v int32) error {
	var b [4]byte
	binary.BigEndian.PutUint32(b[:], uint32(v))
	_, err := w.Write(b[:])
	return err
}

func readWord(r io.Reader) (int32, error) {
	var b [4]byte
	if _, err := io.ReadFull(r, b[:]); err != nil {
		return 0, err
	}
	return int32(binary.BigEndian.Uint32(b[:])), nil
}

// writeString writes a SANE_String: 4-byte length (including NUL
// terminator) followed by the bytes. Empty string is encoded as
// length 0.
func writeString(w io.Writer, s string) error {
	if s == "" {
		return writeWord(w, 0)
	}
	if err := writeWord(w, int32(len(s)+1)); err != nil {
		return err
	}
	if _, err := w.Write([]byte(s)); err != nil {
		return err
	}
	_, err := w.Write([]byte{0})
	return err
}

func readString(r io.Reader) (string, error) {
	n, err := readWord(r)
	if err != nil {
		return "", err
	}
	if n == 0 {
		return "", nil
	}
	if n < 0 || n > 16*1024 {
		return "", fmt.Errorf("sanenet: string length %d out of bounds", n)
	}
	buf := make([]byte, n)
	if _, err := io.ReadFull(r, buf); err != nil {
		return "", err
	}
	// Drop trailing NUL terminator if present.
	if len(buf) > 0 && buf[len(buf)-1] == 0 {
		buf = buf[:len(buf)-1]
	}
	return string(buf), nil
}

func readStatus(r io.Reader) (Status, error) {
	w, err := readWord(r)
	if err != nil {
		return 0, err
	}
	return Status(w), nil
}

// errorFromStatus returns an error if status is not StatusGood.
func errorFromStatus(op string, s Status) error {
	if s == StatusGood {
		return nil
	}
	return fmt.Errorf("sanenet: %s: %s", op, s)
}
```

package sanenet

import (
	"bufio"
	"fmt"
	"io"
	"net"
	"time"
)

// versionCode encodes SANE major.minor.build per the protocol;
// scan-bridge announces 1.0.3.
const clientVersionCode int32 = 0x01000003

// Device is the result of SANE_NET_GET_DEVICES.
type Device struct {
	Name   string
	Vendor string
	Model  string
	Type   string
}

// OptionDescriptor captures the subset of SANE_Option_Descriptor
// that scan-bridge uses (we set string and integer options for the
// avision backend).
type OptionDescriptor struct {
	Index  int
	Name   string
	Title  string
	Desc   string
	Type   int32 // 0=BOOL 1=INT 2=FIXED 3=STRING 4=BUTTON 5=GROUP
	Unit   int32
	Size   int32
	Cap    int32
	Constraint int32
}

// Parameters are returned from SANE_NET_GET_PARAMETERS after the
// scan starts; we use them to size the receive buffer.
type Parameters struct {
	Format        int32
	LastFrame     bool
	BytesPerLine  int32
	PixelsPerLine int32
	Lines         int32
	Depth         int32
}

// Client is a connected, initialised SANE-net session.
type Client struct {
	conn            net.Conn
	rd              *bufio.Reader
	timeout         time.Duration
	PeerVersionCode int32
}

// Dial connects to addr (host:port), runs the SANE_NET_INIT
// handshake, and returns the live Client.
func Dial(addr, username string, timeout time.Duration) (*Client, error) {
	conn, err := net.DialTimeout("tcp", addr, timeout)
	if err != nil {
		return nil, fmt.Errorf("sanenet: dial %s: %w", addr, err)
	}
	c := &Client{
		conn:    conn,
		rd:      bufio.NewReader(conn),
		timeout: timeout,
	}

	// SANE_NET_INIT request: rpc + version_code + username.
	if err := c.writeAll(func(w io.Writer) error {
		if err := writeWord(w, rpcInit); err != nil {
			return err
		}
		if err := writeWord(w, clientVersionCode); err != nil {
			return err
		}
		return writeString(w, username)
	}); err != nil {
		_ = conn.Close()
		return nil, fmt.Errorf("sanenet: init request: %w", err)
	}

	st, err := readStatus(c.rd)
	if err != nil {
		_ = conn.Close()
		return nil, fmt.Errorf("sanenet: init read status: %w", err)
	}
	if err := errorFromStatus("init", st); err != nil {
		_ = conn.Close()
		return nil, err
	}
	ver, err := readWord(c.rd)
	if err != nil {
		_ = conn.Close()
		return nil, fmt.Errorf("sanenet: init read version: %w", err)
	}
	c.PeerVersionCode = ver
	return c, nil
}

// Close sends SANE_NET_EXIT and closes the underlying connection.
// Best effort — errors are returned but the connection is always
// closed.
func (c *Client) Close() error {
	if c == nil || c.conn == nil {
		return nil
	}
	defer c.conn.Close()
	_ = c.writeAll(func(w io.Writer) error { return writeWord(w, rpcExit) })
	c.conn = nil
	return nil
}

// GetDevices returns the list of SANE devices visible to the saned.
func (c *Client) GetDevices() ([]Device, error) {
	if err := c.writeAll(func(w io.Writer) error {
		return writeWord(w, rpcGetDevices)
	}); err != nil {
		return nil, fmt.Errorf("sanenet: get_devices request: %w", err)
	}
	st, err := readStatus(c.rd)
	if err != nil {
		return nil, err
	}
	if err := errorFromStatus("get_devices", st); err != nil {
		return nil, err
	}
	// devices are encoded as a NULL-terminated pointer-array; on
	// the wire each entry is a pointer-flag word + Device fields.
	var out []Device
	for {
		ptr, err := readWord(c.rd)
		if err != nil {
			return nil, err
		}
		if ptr == 0 {
			break
		}
		name, err := readString(c.rd)
		if err != nil {
			return nil, err
		}
		vendor, err := readString(c.rd)
		if err != nil {
			return nil, err
		}
		model, err := readString(c.rd)
		if err != nil {
			return nil, err
		}
		dtype, err := readString(c.rd)
		if err != nil {
			return nil, err
		}
		out = append(out, Device{Name: name, Vendor: vendor, Model: model, Type: dtype})
	}
	return out, nil
}

// Open requests SANE_NET_OPEN for the named device. Returns the
// session handle to use in subsequent calls.
func (c *Client) Open(deviceName string) (int32, error) {
	if err := c.writeAll(func(w io.Writer) error {
		if err := writeWord(w, rpcOpen); err != nil {
			return err
		}
		return writeString(w, deviceName)
	}); err != nil {
		return 0, err
	}
	st, err := readStatus(c.rd)
	if err != nil {
		return 0, err
	}
	if err := errorFromStatus("open", st); err != nil {
		return 0, err
	}
	handle, err := readWord(c.rd)
	if err != nil {
		return 0, err
	}
	// Response also contains a "resource" auth string we don't use.
	_, _ = readString(c.rd)
	return handle, nil
}

// SetStringOption sets a SANE option of type STRING by name.
// The avision backend uses string options for mode and source.
func (c *Client) SetStringOption(handle int32, optIndex int32, value string) error {
	return c.controlOption(handle, optIndex, 1 /* SET */, 3 /* STRING */, []byte(value))
}

// SetIntOption sets an integer-typed option (e.g. resolution).
func (c *Client) SetIntOption(handle int32, optIndex int32, value int32) error {
	var b [4]byte
	be := value
	b[0] = byte(be >> 24)
	b[1] = byte(be >> 16)
	b[2] = byte(be >> 8)
	b[3] = byte(be)
	return c.controlOption(handle, optIndex, 1 /* SET */, 1 /* INT */, b[:])
}

func (c *Client) controlOption(handle, optIndex, action, valueType int32, value []byte) error {
	if err := c.writeAll(func(w io.Writer) error {
		if err := writeWord(w, rpcControlOption); err != nil {
			return err
		}
		if err := writeWord(w, handle); err != nil {
			return err
		}
		if err := writeWord(w, optIndex); err != nil {
			return err
		}
		if err := writeWord(w, action); err != nil {
			return err
		}
		if err := writeWord(w, valueType); err != nil {
			return err
		}
		if err := writeWord(w, int32(len(value))); err != nil {
			return err
		}
		_, err := w.Write(value)
		return err
	}); err != nil {
		return fmt.Errorf("sanenet: control_option request: %w", err)
	}
	st, err := readStatus(c.rd)
	if err != nil {
		return err
	}
	if err := errorFromStatus("control_option", st); err != nil {
		return err
	}
	// Drain info word + result_value_type + value-length + value.
	_, _ = readWord(c.rd)
	_, _ = readWord(c.rd)
	rsLen, err := readWord(c.rd)
	if err != nil {
		return err
	}
	if rsLen > 0 {
		drain := make([]byte, rsLen)
		_, _ = io.ReadFull(c.rd, drain)
	}
	// Resource auth string.
	_, _ = readString(c.rd)
	return nil
}

// Start begins a scan and returns a port to read image bytes from
// (a separate TCP connection to saned), plus the scan parameters.
// Caller is responsible for connecting to that port and reading
// until EOF.
func (c *Client) Start(handle int32) (port int32, byteOrder int32, params Parameters, err error) {
	if err = c.writeAll(func(w io.Writer) error {
		if err := writeWord(w, rpcStart); err != nil {
			return err
		}
		return writeWord(w, handle)
	}); err != nil {
		return 0, 0, Parameters{}, err
	}
	st, err := readStatus(c.rd)
	if err != nil {
		return 0, 0, Parameters{}, err
	}
	if err = errorFromStatus("start", st); err != nil {
		return 0, 0, Parameters{}, err
	}
	port, err = readWord(c.rd)
	if err != nil {
		return 0, 0, Parameters{}, err
	}
	byteOrder, err = readWord(c.rd)
	if err != nil {
		return 0, 0, Parameters{}, err
	}
	// resource auth string
	_, _ = readString(c.rd)
	// GetParameters in the same RPC (saned bundles it).
	params, err = c.getParameters(handle)
	return port, byteOrder, params, err
}

func (c *Client) getParameters(handle int32) (Parameters, error) {
	if err := c.writeAll(func(w io.Writer) error {
		if err := writeWord(w, rpcGetParameters); err != nil {
			return err
		}
		return writeWord(w, handle)
	}); err != nil {
		return Parameters{}, err
	}
	st, err := readStatus(c.rd)
	if err != nil {
		return Parameters{}, err
	}
	if err := errorFromStatus("get_parameters", st); err != nil {
		return Parameters{}, err
	}
	var p Parameters
	for _, dst := range []*int32{&p.Format} {
		w, err := readWord(c.rd)
		if err != nil {
			return Parameters{}, err
		}
		*dst = w
	}
	lf, err := readWord(c.rd)
	if err != nil {
		return Parameters{}, err
	}
	p.LastFrame = lf != 0
	for _, dst := range []*int32{&p.BytesPerLine, &p.PixelsPerLine, &p.Lines, &p.Depth} {
		w, err := readWord(c.rd)
		if err != nil {
			return Parameters{}, err
		}
		*dst = w
	}
	return p, nil
}

func (c *Client) writeAll(fn func(io.Writer) error) error {
	if c.timeout > 0 {
		_ = c.conn.SetWriteDeadline(time.Now().Add(c.timeout))
		defer c.conn.SetWriteDeadline(time.Time{})
	}
	return fn(c.conn)
}

// Package queue implements scan-bridge's in-memory single-worker
// job queue. Each Job runs sequentially; sync HTTP handlers block
// on Wait, async handlers consult Status. The queue is bounded —
// when full, Enqueue returns ErrFull and the HTTP layer turns
// that into 503 + Retry-After.
package queue

import (
	"context"
	"errors"
	"sync"
	"time"
)

// State is the lifecycle of a job in the queue.
type State int

const (
	StateUnknown State = iota
	StateQueued
	StateRunning
	StateDone
	StateFailed
)

func (s State) String() string {
	switch s {
	case StateQueued:
		return "queued"
	case StateRunning:
		return "running"
	case StateDone:
		return "done"
	case StateFailed:
		return "failed"
	default:
		return "unknown"
	}
}

// Errors returned by the queue.
var (
	ErrFull   = errors.New("queue: full")
	ErrClosed = errors.New("queue: closed")
)

// Document is the scan-result-side projection: each scan job
// produces one or more documents (Phase 1.2 always exactly one,
// Phase 1.3 introduces multi-doc QR splitting).
type Document struct {
	ID             string   `json:"id"`
	PaperlessDocID int64    `json:"paperless_doc_id"`
	ASN            string   `json:"asn,omitempty"`
	Pages          int      `json:"pages"`
	Filename       string   `json:"filename"`
	Tags           []string `json:"tags"`
}

// Result is what a scan job returns to its caller.
type Result struct {
	Documents []Document `json:"documents"`
	Warnings  []string   `json:"warnings,omitempty"`
}

// Job is the unit of work. The HTTP layer constructs the Run
// closure capturing the resolved profile and the request body.
type Job struct {
	ID         string
	EnqueuedAt time.Time
	Run        func(ctx context.Context) (Result, error)
}

// QueueOptions configures construction.
type QueueOptions struct {
	Capacity int
}

// Queue is the single-worker queue.
type Queue struct {
	jobs   chan Job
	closed chan struct{}
	closeo sync.Once

	mu    sync.Mutex
	state map[string]*record
}

type record struct {
	state  State
	result Result
	err    error
	done   chan struct{}
}

// New constructs a started Queue. Call Close to stop the worker.
func New(opts QueueOptions) *Queue {
	if opts.Capacity <= 0 {
		opts.Capacity = 16
	}
	q := &Queue{
		jobs:   make(chan Job, opts.Capacity),
		closed: make(chan struct{}),
		state:  map[string]*record{},
	}
	go q.worker()
	return q
}

// Depth returns the number of jobs currently waiting in the buffer
// (excluding any job currently being executed).
func (q *Queue) Depth() int { return len(q.jobs) }

// Close stops the worker after any in-flight job completes. Safe
// to call multiple times.
func (q *Queue) Close() {
	q.closeo.Do(func() {
		close(q.closed)
		close(q.jobs)
	})
}

// Enqueue submits a job. Returns ErrFull when the buffer is at
// capacity, ErrClosed after Close.
func (q *Queue) Enqueue(j Job) error {
	if j.EnqueuedAt.IsZero() {
		j.EnqueuedAt = time.Now()
	}
	q.mu.Lock()
	q.state[j.ID] = &record{state: StateQueued, done: make(chan struct{})}
	q.mu.Unlock()

	select {
	case <-q.closed:
		q.markFailed(j.ID, ErrClosed)
		return ErrClosed
	default:
	}
	select {
	case q.jobs <- j:
		return nil
	default:
		q.markFailed(j.ID, ErrFull)
		return ErrFull
	}
}

// Wait blocks until job ID completes or ctx is cancelled.
func (q *Queue) Wait(ctx context.Context, id string) (Result, error) {
	q.mu.Lock()
	rec, ok := q.state[id]
	q.mu.Unlock()
	if !ok {
		return Result{}, errors.New("queue: unknown job")
	}
	select {
	case <-rec.done:
		if rec.err != nil {
			return Result{}, rec.err
		}
		return rec.result, nil
	case <-ctx.Done():
		return Result{}, ctx.Err()
	}
}

// Status returns the current state for a job ID. ok is false for
// unknown IDs.
func (q *Queue) Status(id string) (State, bool) {
	q.mu.Lock()
	defer q.mu.Unlock()
	rec, ok := q.state[id]
	if !ok {
		return StateUnknown, false
	}
	return rec.state, true
}

func (q *Queue) worker() {
	for j := range q.jobs {
		q.mu.Lock()
		rec := q.state[j.ID]
		rec.state = StateRunning
		q.mu.Unlock()

		ctx := context.Background() // per-job ctx with timeouts is added in Task 9
		res, err := j.Run(ctx)

		q.mu.Lock()
		rec.result = res
		if err != nil {
			rec.err = err
			rec.state = StateFailed
		} else {
			rec.state = StateDone
		}
		close(rec.done)
		q.mu.Unlock()
	}
}

func (q *Queue) markFailed(id string, err error) {
	q.mu.Lock()
	rec, ok := q.state[id]
	if !ok {
		q.mu.Unlock()
		return
	}
	rec.err = err
	rec.state = StateFailed
	close(rec.done)
	q.mu.Unlock()
}

	Status    string `json:"status"`
	StatusURL string `json:"statusUrl"`

// ScanFunc is the callback invoked by the queue for each job.
// Real implementation is wired in Task 11; tests pass a stub.
type ScanFunc func(ctx context.Context, p profile.Profile, req WebhookRequest) (queue.Result, error)

// Sentinel error types so handler maps to the right HTTP code.
var (
	ErrHardwareUnreachable  = errors.New("scan-bridge: hardware unreachable")
	ErrPaperlessUnreachable = errors.New("scan-bridge: paperless unreachable")
)

type webhookHandler struct {
	store *profile.Store
	queue *queue.Queue
	scan  ScanFunc
}

func (h webhookHandler) trigger(w http.ResponseWriter, r *http.Request) {
	token := chi.URLParam(r, "token")
	prof, err := h.store.GetByToken(r.Context(), token)
	if err != nil {
		writeError(w, http.StatusUnauthorized, "unauthorized", "")
		return
	}
	if !prof.Enabled {
		writeError(w, http.StatusConflict, "profile-disabled", "")
		return
	}

	req, err := parseWebhookRequest(r)
	if err != nil {
		writeError(w, http.StatusBadRequest, "invalid-body", err.Error())
		return
	}

	// Determine effective response mode.
	effective := string(prof.Response.DefaultMode)
	if req.ResponseMode != "" {
		effective = req.ResponseMode
	}

	scanID := newScanID()
	job := queue.Job{
		ID: scanID,
		Run: func(ctx context.Context) (queue.Result, error) {
			return h.scan(ctx, prof, req)
		},
	}
	if err := h.queue.Enqueue(job); err != nil {
		if errors.Is(err, queue.ErrFull) {
			w.Header().Set("Retry-After", "30")
			writeError(w, http.StatusServiceUnavailable, "queue-full", "")
			return
		}
		writeError(w, http.StatusInternalServerError, "queue-error", err.Error())
		return
	}

	if effective == string(profile.ResponseAsync) {
		writeJSON(w, http.StatusAccepted, AsyncResponse{
			ScanID:    scanID,
			Status:    "queued",
			StatusURL: "/scans/" + scanID,
		})
		return
	}

	// Sync: wait for job completion.
	ctx, cancel := context.WithTimeout(r.Context(), 5*time.Minute)
	defer cancel()
	res, err := h.queue.Wait(ctx, scanID)
	switch {
	case errors.Is(err, ErrHardwareUnreachable):
		writeError(w, http.StatusBadGateway, "hardware-unreachable", err.Error())
	case errors.Is(err, ErrPaperlessUnreachable):
		writeError(w, http.StatusServiceUnavailable, "paperless-unreachable", err.Error())
	case errors.Is(err, context.DeadlineExceeded):
		writeJSON(w, http.StatusGatewayTimeout, map[string]any{
			"error": "timeout", "scanId": scanID,
			"statusUrl": "/scans/" + scanID,
		})
	case err != nil:
		writeError(w, http.StatusInternalServerError, "internal", err.Error())
	default:
		writeJSON(w, http.StatusOK, SyncResponse{
			ScanID:    scanID,
			Profile:   prof.Name,
			Documents: res.Documents,
			Warnings:  res.Warnings,
		})
	}
}

func parseWebhookRequest(r *http.Request) (WebhookRequest, error) {
	var req WebhookRequest
	if r.Body != nil && r.ContentLength > 0 {
		if err := json.NewDecoder(r.Body).Decode(&req); err != nil {
			return req, err
		}
	}
	q := r.URL.Query()
	if v := q.Get("filename"); v != "" && req.Filename == "" {
		req.Filename = v
	}
	if v := q.Get("tags"); v != "" && len(req.Tags) == 0 {
		req.Tags = strings.Split(v, ",")
	}
	if v := q.Get("tag_strategy"); v != "" && req.TagStrategy == "" {
		req.TagStrategy = v
	}
	if v := q.Get("correspondent"); v != "" && req.Correspondent == "" {
		req.Correspondent = v
	}
	if v := q.Get("document_type"); v != "" && req.DocumentType == "" {
		req.DocumentType = v
	}
	if v := q.Get("owner"); v != "" && req.Owner == "" {
		req.Owner = v
	}
	if v := q.Get("asn"); v != "" && req.ASN == "" {
		req.ASN = v
	}
	if v := q.Get("response_mode"); v != "" && req.ResponseMode == "" {
		req.ResponseMode = v
	}
	return req, nil
}

package output

import (
	"bytes"
	"context"

	"fmt"
	"io"
	"mime/multipart"
	"net/http"
	"net/textproto"
	"strconv"
	"time"

// Paperless is a Dispatcher that uploads to a Paperless-ngx
// instance via its REST API.
type Paperless struct {
	BaseURL string
	Token   string
	HTTP    *http.Client
}

// NewPaperless builds a Paperless dispatcher with sensible defaults.
func NewPaperless(baseURL, token string) *Paperless {
	return &Paperless{
		BaseURL: trimRightSlash(baseURL),
		Token:   token,
		HTTP:    &http.Client{Timeout: 60 * time.Second},
	}
}

// PaperlessDocument is the per-call document description.
type PaperlessDocument = Document

// Dispatch implements Dispatcher.
func (p *Paperless) Dispatch(ctx context.Context, doc Document) (Result, error) {
	id, err := p.PostDocument(doc)
	if err != nil {
		return Result{}, err
	}
	return Result{PaperlessDocID: id}, nil
}

// PostDocument uploads doc and returns the new document ID.
func (p *Paperless) PostDocument(doc Document) (int64, error) {
	var body bytes.Buffer
	mw := multipart.NewWriter(&body)

	// "document" field — the file itself.
	hdr := make(textproto.MIMEHeader)
	hdr.Set("Content-Disposition",
		fmt.Sprintf(`form-data; name="document"; filename="%s"`, doc.Filename))
	hdr.Set("Content-Type", "application/pdf")
	part, err := mw.CreatePart(hdr)
	if err != nil {
		return 0, fmt.Errorf("output.paperless: multipart part: %w", err)
	}
	if _, err := io.Copy(part, doc.Content); err != nil {
		return 0, fmt.Errorf("output.paperless: copy body: %w", err)
	}

	// Optional metadata fields.
	for _, kv := range []struct{ k, v string }{
		{"title", trimExt(doc.Filename)},
		{"correspondent", doc.Correspondent},
		{"document_type", doc.DocumentType},
		{"archive_serial_number", doc.ASN},
		{"owner", doc.Owner},
	} {
		if kv.v == "" {
			continue
		}
		_ = mw.WriteField(kv.k, kv.v)
	}
	for _, t := range doc.Tags {
		_ = mw.WriteField("tags", t)
	}
	if err := mw.Close(); err != nil {
		return 0, fmt.Errorf("output.paperless: close multipart: %w", err)
	}

	req, err := http.NewRequest(http.MethodPost,
		p.BaseURL+"/api/documents/post_document/", &body)
	if err != nil {
		return 0, err
	}
	req.Header.Set("Content-Type", mw.FormDataContentType())
	req.Header.Set("Authorization", "Token "+p.Token)

	resp, err := p.HTTP.Do(req)
	if err != nil {
		return 0, fmt.Errorf("output.paperless: post: %w", err)
	}
	defer resp.Body.Close()

	if resp.StatusCode/100 != 2 {
		return 0, fmt.Errorf("output.paperless: unexpected status %d", resp.StatusCode)
	}
	// Paperless's post_document returns either {"id": N} or a UUID
	// string for the task. Phase 1.2 handles only the {"id": N}
	// shape; if the deployment uses async ingest we expand later.
	var parsed struct {
		ID int64 `json:"id"`
	}
	if err := json.NewDecoder(resp.Body).Decode(&parsed); err != nil {
		return 0, fmt.Errorf("output.paperless: decode response: %w", err)
	}
	return parsed.ID, nil
}

// NextASN computes the next ASN by querying for the document with
// the highest current archive_serial_number and incrementing.
// Caller must serialise concurrent uses (the scan-bridge job queue
// already does, since only one scan runs at a time).
func (p *Paperless) NextASN() (int64, error) {
	req, err := http.NewRequest(http.MethodGet,
		p.BaseURL+"/api/documents/?ordering=-archive_serial_number&page_size=1", nil)
	if err != nil {
		return 0, err
	}
	req.Header.Set("Authorization", "Token "+p.Token)
	resp, err := p.HTTP.Do(req)
	if err != nil {
		return 0, fmt.Errorf("output.paperless: next-asn: %w", err)
	}
	defer resp.Body.Close()
	if resp.StatusCode/100 != 2 {
		return 0, fmt.Errorf("output.paperless: next-asn: status %d", resp.StatusCode)
	}
	var page struct {
		Results []struct {
			ASN int64 `json:"archive_serial_number"`
		} `json:"results"`
	}
	if err := json.NewDecoder(resp.Body).Decode(&page); err != nil {
		return 0, fmt.Errorf("output.paperless: decode next-asn: %w", err)
	}
	if len(page.Results) == 0 {
		return 1, nil
	}
	return page.Results[0].ASN + 1, nil
}

func trimRightSlash(s string) string {
	for len(s) > 0 && s[len(s)-1] == '/' {
		s = s[:len(s)-1]
	}
	return s
}

func trimExt(s string) string {
	for i := len(s) - 1; i >= 0; i-- {
		if s[i] == '.' {
			return s[:i]
		}
	}
	return s
}

var _ = strconv.Itoa // keep strconv usable for future extensions
var _ context.Context // demonstrate ctx availability

// Package processor turns the raw byte-stream from sane-runtime
// into one or more PDF documents. Phase 1.2 ships the Stub
// implementation: it pastes pages 1:1 into a single PDF with no
// OCR or splitting. Phase 1.3 introduces the real implementation.
package processor

import (
	"bytes"
	"fmt"
	"image"
	_ "image/jpeg"
	_ "image/png"

	"github.com/jung-kurt/gofpdf"
)

// Input is what the scanner orchestrator hands to the processor.
type Input struct {
	// Pages contains the raw page images. The Stub processor
	// accepts PNG or JPEG; the real Phase 1.3 processor will accept
	// PNM and do all conversions internally.
	Pages [][]byte
}

// Output is one assembled document.
type Output struct {
	PDF       []byte
	PageCount int
	ASN       string // Stub never sets this; Phase 1.3 will from QR codes.
}

// Processor is the interface scanner orchestration depends on.
type Processor interface {
	Process(in Input) ([]Output, error)
}

// Stub is the Phase-1.2 minimal processor.
type Stub struct{}

// NewStub returns a Stub processor.
func NewStub() *Stub { return &Stub{} }

// Process implements Processor.
func (s *Stub) Process(in Input) ([]Output, error) {
	if len(in.Pages) == 0 {
		return nil, fmt.Errorf("processor: no pages to process")
	}
	pdf := gofpdf.New("P", "mm", "A4", "")
	for i, page := range in.Pages {
		img, _, err := image.Decode(bytes.NewReader(page))
		if err != nil {
			return nil, fmt.Errorf("processor: decode page %d: %w", i, err)
		}
		bounds := img.Bounds()
		// Register the image and place it on the page. gofpdf's
		// "RegisterImageOptions" wants a sniff-able format; we wrote
		// PNG into Pages[i] via the test, but real scans give us
		// JPEG. Both are supported.
		opts := gofpdf.ImageOptions{ReadDpi: false, ImageType: "PNG"}
		// Try PNG first; fall back to JPEG on parse error.
		nameKey := fmt.Sprintf("page-%d", i)
		_ = bounds
		if _, err := registerImage(pdf, nameKey, opts, page); err != nil {
			opts.ImageType = "JPG"
			if _, err := registerImage(pdf, nameKey, opts, page); err != nil {
				return nil, fmt.Errorf("processor: register page %d: %w", i, err)
			}
		}
		pdf.AddPage()
		pdf.ImageOptions(nameKey, 0, 0, 210, 297, false, opts, 0, "")
	}
	var buf bytes.Buffer
	if err := pdf.Output(&buf); err != nil {
		return nil, fmt.Errorf("processor: pdf output: %w", err)
	}
	return []Output{{
		PDF:       buf.Bytes(),
		PageCount: len(in.Pages),
	}}, nil
}

func registerImage(pdf *gofpdf.Fpdf, name string, opts gofpdf.ImageOptions, data []byte) (gofpdf.ImageOptions, error) {
	pdf.RegisterImageOptionsReader(name, opts, bytes.NewReader(data))
	if err := pdf.Error(); err != nil {
		return opts, err
	}
	return opts, nil
}

```go
// Package scanner orchestrates a single scan job: drive SANE, run
// the processor, and dispatch outputs. It is the implementation of
// the api.ScanFunc interface used by the webhook handler.
package scanner

import (
	"context"
	"crypto/rand"
	"encoding/hex"
	"fmt"
	"strings"
	"time"

	"github.com/strausmann/paperless-scan-bridge/components/scan-bridge/internal/api"
	"github.com/strausmann/paperless-scan-bridge/components/scan-bridge/internal/output"
	"github.com/strausmann/paperless-scan-bridge/components/scan-bridge/internal/processor"
	"github.com/strausmann/paperless-scan-bridge/components/scan-bridge/internal/profile"
	"github.com/strausmann/paperless-scan-bridge/components/scan-bridge/internal/queue"
	"github.com/strausmann/paperless-scan-bridge/components/scan-bridge/internal/tag"
)

// SANEDriver is implemented by anything that can produce raw page
// images for a profile. The real implementation wraps internal/sanenet.
type SANEDriver interface {
	Scan(ctx context.Context, p profile.Profile) ([][]byte, error)
}

// DispatcherBuilder turns a profile.Output into a concrete output.Dispatcher.
// Phase 1.2 only knows paperless-api; the builder can fail-fast on
// unknown targets.
type DispatcherBuilder interface {
	Build(out profile.Output) (output.Dispatcher, error)
}

// Request is the parsed webhook input, deduplicated from api.WebhookRequest.
type Request = api.WebhookRequest

// Deps wires the orchestrator.
type Deps struct {
	SANE        SANEDriver
	Processor   processor.Processor
	Dispatchers DispatcherBuilder
}

// Scanner is the runtime instance of the orchestrator.
type Scanner struct {
	deps Deps
}

// New constructs a Scanner.
func New(d Deps) *Scanner { return &Scanner{deps: d} }

// Scan implements api.ScanFunc.
func (s *Scanner) Scan(ctx context.Context, p profile.Profile, r Request) (queue.Result, error) {
	pages, err := s.deps.SANE.Scan(ctx, p)
	if err != nil {
		return queue.Result{}, mapSANEError(err)
	}
	if len(pages) == 0 {
		return queue.Result{}, fmt.Errorf("scanner: no pages produced")
	}

	docs, err := s.deps.Processor.Process(processor.Input{Pages: pages})
	if err != nil {
		return queue.Result{}, fmt.Errorf("scanner: process: %w", err)
	}

	out := queue.Result{}
	for i, doc := range docs {
		filename := buildFilename(p, r, i)
		mergedTags := tag.Merge(p.Paperless.DefaultTags,
			p.Paperless.DefaultTagStrategy,
			r.Tags, profile.TagStrategy(r.TagStrategy))

		dispatched, err := s.dispatchAll(ctx, p, output.Document{
			Filename:      filename,
			Content:       readerOf(doc.PDF),
			Tags:          mergedTags,
			ASN:           pickASN(r, doc),
			Correspondent: pick(r.Correspondent, p.Paperless.Correspondent),
			DocumentType:  pick(r.DocumentType, p.Paperless.DocumentType),
			Owner:         pick(r.Owner, p.Paperless.Owner),
		})
		if err != nil {
			return queue.Result{}, mapDispatchError(err)
		}
		out.Documents = append(out.Documents, queue.Document{
			ID:             newDocID(),
			PaperlessDocID: dispatched.PaperlessDocID,
			ASN:            pickASN(r, doc),
			Pages:          doc.PageCount,
			Filename:       filename,
			Tags:           mergedTags,
		})
	}
	return out, nil
}

func (s *Scanner) dispatchAll(ctx context.Context, p profile.Profile, doc output.Document) (output.Result, error) {
	if len(p.Outputs) == 0 {
		return output.Result{}, fmt.Errorf("scanner: profile has no outputs")
	}
	// Phase 1.2 returns the result of the first output; multi-output
	// would aggregate.
	first := p.Outputs[0]
	disp, err := s.deps.Dispatchers.Build(first)
	if err != nil {
		return output.Result{}, err
	}
	return disp.Dispatch(ctx, doc)
}

// --- small helpers ---------------------------------------------------------

func buildFilename(p profile.Profile, r Request, _ int) string {
	pat := p.Naming.Pattern
	if r.Filename != "" {
		pat = r.Filename
	}
	pat = strings.ReplaceAll(pat, "{date}", time.Now().UTC().Format("20060102"))
	pat = strings.ReplaceAll(pat, "{time}", time.Now().UTC().Format("150405"))
	pat = strings.ReplaceAll(pat, "{profile}", p.Name)
	if pat == "" {
		pat = p.Name + ".pdf"
	}
	return pat
}

func pick(a, b string) string {
	if a != "" {
		return a
	}
	return b
}

func pickASN(r Request, _ processor.Output) string {
	return r.ASN
}

func newDocID() string {
	var b [6]byte
	_, _ = rand.Read(b[:])
	return "doc-" + hex.EncodeToString(b[:])
}

func readerOf(b []byte) interface{ Read(p []byte) (int, error) } {
	return &byteReader{b: b}
}

type byteReader struct {
	b []byte
	i int
}

func (r *byteReader) Read(p []byte) (int, error) {
	if r.i >= len(r.b) {
		return 0, fmt.Errorf("EOF")
	}
	n := copy(p, r.b[r.i:])
	r.i += n
	return n, nil
}

// mapSANEError maps low-level errors into the sentinels the API
// layer uses for HTTP-status mapping.
func mapSANEError(err error) error {
	if err == nil {
		return nil
	}
	return fmt.Errorf("%w: %s", api.ErrHardwareUnreachable, err.Error())
}

func mapDispatchError(err error) error {
	if err == nil {
		return nil
	}
	return fmt.Errorf("%w: %s", api.ErrPaperlessUnreachable, err.Error())
}
```

scanimage -L || true

```go
func (p *productionSANE) Scan(ctx context.Context, prof profile.Profile) ([][]byte, error) {
	client, err := sanenet.Dial(p.addr, "scan-bridge", 30*time.Second)
	if err != nil {
		return nil, err
	}
	defer client.Close()

	devices, err := client.GetDevices()
	if err != nil {
		return nil, err
	}
	if len(devices) == 0 {
		return nil, fmt.Errorf("sanenet: no devices reported")
	}

	// Phase 1.2 picks the first device. Multi-device deployments
	// are out of scope (would need a profile.Scan.DeviceName field).
	handle, err := client.Open(devices[0].Name)
	if err != nil {
		return nil, err
	}

	// TODO Phase 1.3: discover option indices via SANE_NET_GET_OPTION_DESCRIPTORS
	// For Phase 1.2 we use an avision-specific layout that matches
	// the reference Kodak i1120 (mode=2, resolution=3, source=6,
	// brightness=22, contrast=23 from `scanimage -A` empirical run).
	if err := client.SetStringOption(handle, 2, prof.Scan.Mode); err != nil {
		return nil, err
	}
	if err := client.SetIntOption(handle, 3, int32(prof.Scan.Resolution)); err != nil {
		return nil, err
	}
	if err := client.SetStringOption(handle, 6, prof.Scan.Source); err != nil {
		return nil, err
	}
	if err := client.SetIntOption(handle, 22, int32(prof.Scan.Brightness)); err != nil {
		return nil, err
	}
	if err := client.SetIntOption(handle, 23, int32(prof.Scan.Contrast)); err != nil {
		return nil, err
	}

	var pages [][]byte
	for {
		port, byteOrder, params, err := client.Start(handle)
		if err != nil {
			// NO_DOCS at start of next page is the natural ADF-empty signal.
			if isNoDocs(err) {
				return pages, nil
			}
			return pages, err
		}
		_ = byteOrder
		_ = params
		page, err := readImageStream(p.addr, port, ctx)
		if err != nil {
			return pages, err
		}
		pages = append(pages, page)
		if len(pages) >= 100 {
			return pages, fmt.Errorf("sanenet: page cap (100) reached — possible runaway")
		}
	}
}

func isNoDocs(err error) bool {
	return err != nil && (errorContains(err, "NO_DOCS") || errorContains(err, "EOF"))
}

func errorContains(err error, sub string) bool {
	return err != nil && (err.Error() == sub || (len(err.Error()) > 0 && (indexOf(err.Error(), sub) >= 0)))
}

func indexOf(s, sub string) int {
	for i := 0; i+len(sub) <= len(s); i++ {
		if s[i:i+len(sub)] == sub {
			return i
		}
	}
	return -1
}

// readImageStream connects to the side-channel port returned by
// SANE_NET_START and reads the page bytes until EOF. The protocol
// frames bytes as: 4-byte length (or 0xFFFFFFFF for EOF) + payload.
func readImageStream(saneAddr string, port int32, ctx context.Context) ([]byte, error) {
	host, _, ok := splitHostPort(saneAddr)
	if !ok {
		return nil, fmt.Errorf("sanenet: bad addr %q", saneAddr)
	}
	conn, err := dialContextWithTimeout(ctx, fmt.Sprintf("%s:%d", host, port), 30*time.Second)
	if err != nil {
		return nil, err
	}
	defer conn.Close()

	var out []byte
	buf := make([]byte, 4)
	chunk := make([]byte, 64*1024)
	for {
		if _, err := readFull(conn, buf); err != nil {
			return out, err
		}
		n := int32(uint32(buf[0])<<24 | uint32(buf[1])<<16 | uint32(buf[2])<<8 | uint32(buf[3]))
		if n == -1 {
			return out, nil // EOF marker
		}
		if n <= 0 {
			return out, fmt.Errorf("sanenet: stream length %d", n)
		}
		remaining := int(n)
		for remaining > 0 {
			step := remaining
			if step > len(chunk) {
				step = len(chunk)
			}
			rd, err := conn.Read(chunk[:step])
			if err != nil {
				return out, err
			}
			out = append(out, chunk[:rd]...)
			remaining -= rd
		}
	}
}

func splitHostPort(addr string) (host, port string, ok bool) {
	for i := len(addr) - 1; i >= 0; i-- {
		if addr[i] == ':' {
			return addr[:i], addr[i+1:], true
		}
	}
	return "", "", false
}

func readFull(c io.Reader, buf []byte) (int, error) {
	n := 0
	for n < len(buf) {
		r, err := c.Read(buf[n:])
		if err != nil {
			return n, err
		}
		n += r
	}
	return n, nil
}

func dialContextWithTimeout(ctx context.Context, addr string, timeout time.Duration) (net.Conn, error) {
	d := net.Dialer{Timeout: timeout}
	return d.DialContext(ctx, "tcp", addr)
}
```

```markdown
# Webhook reference

Every profile gets one webhook URL. POST anything (or nothing) to it
and a scan happens.

## URL

```
POST https://<your-host>/webhooks/<token>
```

Token: 43 URL-safe characters (base64url-encoded 32 random bytes).
Generated when the profile is created. Knowing the token *is* the
authorisation; rotate it when leaked.

## Body (optional)

JSON body, all fields optional. Anything not present uses the
profile defaults.

| Field | Type | Default | Notes |
|---|---|---|---|
| `filename` | string template | profile.naming.pattern | `{date}`, `{time}`, `{profile}`, `{counter}` substituted |
| `tags` | string[] | profile.paperless.default_tags | Caller-side tags (see `tag_strategy`) |
| `tag_strategy` | `add` \| `override` \| `remove` | profile.default_tag_strategy | How `tags` interact with the profile defaults |
| `correspondent` | string | profile.paperless.correspondent | |
| `document_type` | string | profile.paperless.document_type | |
| `owner` | string | profile.paperless.owner | Paperless user |
| `asn` | string | (none) | Force a specific ASN on the first document |
| `response_mode` | `sync` \| `async` | profile.response.default_mode | |

## Query parameters (alternative to body)

For callers that can only configure a URL (some HA shortcuts,
shell scripts), the same fields can be passed as query params:

```
POST /webhooks/<token>?response_mode=async&tags=Vodafone,2026-Q2&tag_strategy=override
```

If both query and body provide the same field, the body wins.

## Tag-merge matrix

Final tag list = `Merge(profile.default_tags, profile.default_tag_strategy,
caller.tags, caller.tag_strategy)`:

- If `caller.tags` is empty, the result is just the defaults.
- Else effective strategy = `caller.tag_strategy` if set, otherwise
  `profile.default_tag_strategy`.
- `add`: union of defaults and caller, deduplicated.
- `override`: caller list, deduplicated.
- `remove`: defaults minus caller.

## Sync response

HTTP 200, body shape:

```json
{
  "scanId": "scan-...",
  "profile": "Quick BW",
  "documents": [
    {
      "id": "doc-...",
      "paperless_doc_id": 4711,
      "asn": "",
      "pages": 1,
      "filename": "20260430-quick-bw.pdf",
      "tags": ["AutoScan"]
    }
  ],
  "durationMs": 9234
}
```

Sync waits up to 5 minutes. Beyond that the response is HTTP 504
with the `scanId` so the caller can poll `/scans/<scanId>`.

## Async response

HTTP 202, body shape:

```json
{
  "scanId": "scan-...",
  "status": "queued",
  "statusUrl": "/scans/scan-..."
}
```

Poll `GET /scans/<scanId>` for `status` ∈ `queued | running | done | failed`.

## Errors

| Code | Body `error` field | Cause |
|---|---|---|
| 400 | `invalid-json`, `invalid-body`, `validation` | malformed input |
| 401 | `unauthorized` | unknown or rotated token |
| 409 | `profile-disabled` | profile is `enabled: false` |
| 500 | `internal`, `queue-error` | bug or server problem |
| 502 | `hardware-unreachable` | scanner offline / SANE-net unreachable |
| 503 | `paperless-unreachable`, `queue-full` | Paperless or queue saturated |
| 504 | `timeout` | sync mode hit the 5-min cap (use async) |
```

# Profile schema reference

  contrast: 0                     # -100..100

  on_missing_first_asn: "auto-create"  # auto-create | error — only required mode
  blank_threshold: 0.95           # only disabled mode

paperless:

  correspondent: "Vodafone GmbH"  # optional

metadata:

## Splitting modes

Phase 1.2 supports two mutually exclusive splitting strategies.

### `asn_mode: required`

Pages are grouped by Paperless ASN-style QR-code stickers. Each
QR-bearing page boundary starts a new document. The decoded ASN
is stored as `archive_serial_number` on the resulting Paperless
document.

- `asn_page_handling: discard` — the QR page is a separator, not
  document content (cover sheet usage)
- `asn_page_handling: keep` — the QR page is page 1 of the document
  (sticker on the document itself)
- `on_missing_first_asn: auto-create` — when the first scanned
  page has no QR, scan-bridge requests a fresh ASN from Paperless
  and assigns it
- `on_missing_first_asn: error` — fails the scan if the first page
  lacks a QR

### `asn_mode: disabled`

Documents are separated by **blank pages**. Blank pages are detected
by a per-profile threshold of bright-pixel ratio (default 0.95).
Blank pages are always discarded — they are separators, never
content.

A stack with no blank pages becomes one multi-page document.

## Validation

Profiles fail validation (HTTP 400) when:

- `name` is empty
- `token` shorter than 40 chars
- `scan.resolution` outside 75–600
- `scan.mode` not in `Lineart | Gray | Color`
- `splitting.asn_mode` not in `required | disabled`
- in required mode, `asn_page_handling` or `on_missing_first_asn`
  invalid
- `paperless.default_tag_strategy` not in `add | override | remove`
- `outputs` empty or contains an unsupported `target`
- any output missing `api_url` or `api_token_secret`
- `response.default_mode` not in `sync | async`

## Phase 1.2 limits

- Only `target: paperless-api` is implemented. The schema lists
  `outputs` as an array for forward compatibility — adding NFS, S3,
  or custom outputs lands in Phase 2.x.
- The QR-decode and blank-page logic lives in the Phase 1.3
  `scan-processor`. Phase 1.2 ships a stub that produces one
  multi-page PDF per scan regardless of `splitting`. The schema is
  validated and persisted today; the runtime behaviour follows
  in 1.3.

# Configuration

scan-bridge reads three categories of config:

1. **Environment variables** for runtime defaults
2. **Profile DB** for per-route configuration (the SQLite
   `/data/profiles.db`)
3. **Secrets** resolved by name from one of three sources

## Environment variables

| Variable | Default | Notes |
|---|---|---|
| `SCAN_BRIDGE_DB_PATH` | `/data/profiles.db` | SQLite location |
| `SCAN_BRIDGE_HTTP_ADDR` | `:8080` | listen address |
| `SCAN_BRIDGE_SANE_NET_ADDR` | `sane-runtime:6566` | saned target |
| `SCAN_BRIDGE_LOG_LEVEL` | `info` | `debug | info | warn | error` |
| `SCAN_BRIDGE_SECRETS_FILE` | unset | optional SOPS file path |
| `SCAN_BRIDGE_AGE_KEY_FILE` | unset | private age key for SOPS |

## Secrets

Secrets are resolved by name in this order:

1. **Docker secret:** `/run/secrets/<name>` — recommended for
   compose / swarm
2. **Environment variable:** `<NAME-uppercase>` — recommended for
   simple deployments
3. **SOPS-encrypted file** at `SCAN_BRIDGE_SECRETS_FILE`,
   decrypted with the age key at `SCAN_BRIDGE_AGE_KEY_FILE` —
   recommended for "secrets in git" repositories

Profiles reference secrets by name only:

```yaml
outputs:
  - target: paperless-api
    api_token_secret: paperless_api_token
```

The string `paperless_api_token` is the lookup key. Plaintext
tokens in YAML are **rejected at parse time** — use the
`api_token_secret` reference, never `api_token`.

## Production hardening

- TLS termination via your reverse proxy of choice (Traefik,
  Caddy, nginx). scan-bridge speaks plain HTTP — terminate TLS
  upstream.
- Run scan-bridge as the `nonroot` user (the distroless base
  image already does)
- Mount `/data` from a backed-up volume — losing the SQLite means
  losing every profile and every webhook URL
- Restrict the bridge's outbound network to Paperless and the
  sane-runtime container; scan-bridge does not need general
  internet access
- The `sane-runtime` container holds the USB device and runs
  `saned` — keep it on the internal compose network only, never
  expose 6566 to the host

## Backups

The single file you must back up: `/data/profiles.db`.

A simple cron-based scheme:

```bash
sqlite3 /data/profiles.db ".backup '/backup/profiles-$(date +%Y%m%d).db'"
```

Restore is a file copy. Profiles are restored, webhook tokens are
unchanged, the bridge resumes serving callers without
re-configuration.
